# 메인 기능 E2E 테스트 설계

**목적:** 게임 규칙과 별개로 앱의 오버레이·프로세스 경계에서 확인할 동작을 정의한다.

**요약:** 창 조작과 OS 상호작용은 O-01~O-11, 창 설정 재실행 초기화는 E2E-18, Preload·Main 신뢰 경계는 E2E-21로 확인한다. 현재 구현·미검증 범위는 [메인 E2E 현황](e2e-implementation-status.md), 세션별 실행 결과는 [세션 목록](../session-reports/session-list.md)을 따른다.

## 범위와 시나리오

### 오버레이 검증

| ID | 시나리오 | 합격 조건 |
| --- | --- | --- |
| O-01 | 밝은/어두운 화면 | 투명 배경·흑백 정보·20–100% 불투명도 조절이 정상이며 20% 미만으로 내려가지 않는다. |
| O-02 | 업무 앱 입력 중 복원·호버·게임 버튼 클릭 | 자동 포커스 이동이 없고 버튼 첫 클릭이 실행된다. |
| O-03 | 현재 블랙잭 금액 편집·접근성 창 계획 | 현재 블랙잭 숫자칸을 명시적으로 누를 때만 임시 포커스를 받고, 편집 종료 후 비집중·비활성으로 돌아간다. 접근성 창은 후속 범위다. |
| O-04 | 전체 클릭 통과 | 아래 앱에 클릭·스크롤을 전달하고 트레이에서 복구할 수 있다. |
| O-05 | 사용자 정의 크기 조절·접기 | 실제 창 크기가 바뀌고 투명도가 유지되며 UI가 잘리지 않는다. |
| O-06 | 모니터 분리·음수 좌표·배율 | 창이 workArea 안으로 돌아오고 좌표가 튀지 않는다. |
| O-07 | Spaces·가상 데스크톱·전체 화면 | OS별 동작을 기록하고 트레이에서 복구할 수 있다. |
| O-08 | suspend/resume·재실행 | 중복 창·타이머·잘못된 위치가 없고 재실행 시 창 설정은 기본값, 현재 블랙잭 세션은 저장 상태로 돌아온다. |
| O-09 | Renderer 재로드·종료 | Main의 현재 블랙잭 상태를 보존하고 공개 상태를 다시 동기화한다. |
| O-10 | 자동 부분 클릭 통과 실험 | 빠른 진입·클릭·스크롤에서 오입력이 없다. |
| O-11 | 전역 Alt+백틱 숨김·복원 | 다른 앱 사용 중 숨기고 재입력 시 포커스 이동 없이 복원한다. 트레이 복구가 가능하며 충돌·키보드 배열을 OS별로 기록한다. |

O-01~O-09와 O-11은 제품 검증 조건이고 O-10은 별도 실험이다. O-06 전체와 O-08의 창 설정 전체 재실행 초기화는 S11과 함께 TOBE로 보류한다. 게임 세션 복원 등 O-08의 나머지 조건은 유지한다. O-05 실패를 고정 크기 UI로 대체해 완료 처리하지 않는다. DevTools가 열린 투명 창의 합성은 최종 판정 근거로 사용하지 않는다.

### 창 설정과 신뢰 경계

| ID | 시나리오 | 합격 조건 |
| --- | --- | --- |
| E2E-18 | 색상·불투명도·접힘·크기·위치·클릭 통과 변경 후 재기동 | 창 설정은 기본 색상·65%·펼침·280×180 DIP·기본 위치·대화형으로 돌아가고, 현재 블랙잭 판·잔액은 유지된다. S11과 함께 보류했다. |
| E2E-21 | Node 격리·IPC 신뢰 경계 | `window.require`가 없고 비신뢰 문서의 snapshot 요청·상태 push 및 비정상 IPC 명령을 거부한다. |

현재 테스트가 블랙잭 화면이나 상태를 사용하더라도 창·신뢰 경계의 공통 동작과 [블랙잭 게임 여정](../games/blackjack/e2e-test-plan.md)의 완료 조건을 구분한다. 블랙잭 명령 스키마와 비공개 카드 노출 검증의 구체적인 계약은 [블랙잭 기술 설계](../games/blackjack/technical-design.md)를 따른다.

## 실행과 판정

- Electron 프로덕션 패키지에서 실제 창·Preload·Main 경로를 확인한다. 실행 명령과 파일별 현재 범위는 [메인 E2E 현황](e2e-implementation-status.md)에 기록한다.
- 자동화 결과만으로 다른 앱의 클릭·스크롤 전달, 실제 포커스 복귀, 투명도 OS 합성, 물리 단축키·트레이 입력, 물리 모니터 변화를 통과로 판정하지 않는다. OS와 장비를 명시한 수동 확인 결과는 해당 [세션 보고서](../session-reports/session-list.md)에 남긴다.
- E2E-18과 O-06 전체, O-08의 창 설정 전체 재실행 초기화는 보류 상태다. 다음 실행 순서는 [로드맵](../work-session-roadmap.md)을 따른다.
