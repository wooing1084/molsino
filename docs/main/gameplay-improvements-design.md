# N04 게임성 개선 설계 결정

**목적:** N04의 초기 정책과 담당 기준 문서를 연결하고 후속 밸런스 검토의 출발점을 남긴다.

**요약:** 투명도 조절창 동기화, 여섯 공통 레벨과 한도, 순차 카드 공개를 구현에 반영했다. 현재 잔액 입장 정책과 450/140/300ms 공개 시간은 구현 초기값이다. 상세 제품·기술 계약은 담당 문서 한 곳에서 관리하며 최종 통합 검증은 N04 보고서를 따른다.

## 1. 확정한 초기 정책

- ‘투명 스크롤’은 흑백 버튼에 호버하면 나타나는 불투명도 조절창이다. 조절창 전체와 게임 창에 같은 설정 알파를 한 번 적용한다.
- 두 게임과 바카라 P/B/T는 같은 여섯 레벨의 기본 베팅 최소·최대액을 사용한다. 블랙잭 추가 베팅은 기존 규칙과 잔액 조건을 따른다.
- 다른 레벨에 입장할 때 현재 잔액을 검사한다. 선택한 방은 손실 뒤에도 유지하고 최소액 부족 시 하위 방을 안내한다. 최고 달성 기록은 정산 후 최고 잔액에서 파생하며 영구 입장 해금과 다르다.
- 확정 레벨은 공통 헤더, 최소·최대는 게임의 고정 행에 표시한다. 메뉴 안의 가로 카드 페이지에서 탐색하고 적용 저장에 성공해야 레벨을 변경한다.
- 카드 공개는 라운드 첫 카드 즉시, 이후 450ms 간격·140ms 페이드·최종 결과 300ms 지연이다. Main의 정산과 별개이며 숨김 복원·reload는 최신 공개 상태로 맞춘다.
- 수치와 시간은 플레이 피드백에 따라 후속 조정할 수 있는 초기 정책이다. 현재 계약은 더 이상 ‘미확정 제안’이 아니다.

## 3. 설계 이력과 검증

초안의 사용자 의견 수렴과 카지노 금액대 조사 이력은 [D02 보고서](../session-reports/D02-gameplay-improvements-design.md)에 남긴다. 카지노별 공개 금액은 molsino의 보장 조건이 아니며 현재 레벨은 시작 자금 $100에 맞춘 게임 정책이다.

최종 E2E·최소 창 시각 확인·회귀 결과를 기록하기 전에는 세션을 완료로 표시하지 않는다. DOM/CSS 확인을 실제 Windows 동작이나 외부 앱 포커스·OS 투명 합성의 검증으로 확대하지 않는다. 다음 세션의 시작 조건은 [로드맵](../work-session-roadmap.md)을 따른다.
