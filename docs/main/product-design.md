**목적:** 게임을 다른 앱 위에서 사용하는 데 필요한 공통 제품 경험과 오버레이 동작을 정의한다.

**요약:** 작은 투명 창의 표시·입력·이동·크기·복구 정책과 앱 차원의 완료 기준을 다룬다. 현재 게임의 화면과 규칙은 [블랙잭 제품 설계](../games/blackjack/product-design.md), 신규 게임은 [바카라 제품 설계](../games/baccarat/product-design.md), 구체적인 Electron 계약은 [메인 기술 설계](technical-design.md)를 따른다.

## 1. 제품 방향

molsino는 다른 앱을 사용하는 동안 작은 펫처럼 띄워 두고 필요할 때 짧게 플레이하는 로컬 싱글플레이 카지노 게임이다. 현재 제공하는 게임은 블랙잭이다. 화면 대부분을 투명하게 비우고 필요한 정보와 조작만 흑백으로 표시한다. 아래 앱의 입력과 키보드 포커스를 방해하지 않는 것이 중요하다.

- 사용자가 창의 위치와 크기를 조절할 수 있다.
- 배경은 최대한 투명하게, 색상은 흰색과 검은색으로 제한한다.
- 현재 블랙잭은 소리·알림·큰 승리 효과 없이 결과를 짧은 문장으로 표시한다. 구체적인 승패 표현은 [블랙잭 화면 구성](../games/blackjack/product-design.md#2-블랙잭-화면-구성)을 따른다.
- macOS와 Windows에서 공통 Electron 앱을 사용한다. 플랫폼 정책과 프로세스 경계는 [메인 기술 설계](technical-design.md)를 따른다.

## 2. 오버레이와 조작

### 창

창 크기는 화면 배율에 독립적인 DIP 단위이며 Electron에서 OS별 물리 픽셀로 변환한다.

| 항목 | 제안값 / 동작 |
| --- | --- |
| 기본 크기 | 280 × 180 DIP |
| 최소 / 최대 | 220 × 150 / 420 × 280 DIP |
| 이동 | 상단의 짧은 드래그 영역을 잡아 이동 |
| 크기 조절 | 모서리 핸들로 조절, 호버 시 핸들 표시 |
| 표시 위치 | 일반 앱 창 위에 유지, 사용자가 끄기 가능 |
| 접기 | 내부 접힘 상태는 유지하되, 오해를 낳은 헤더의 `▁` 접기 버튼은 표시하지 않음 |
| 숨기기 / 복원 | 헤더 `−` 버튼·전역 Alt+백틱으로 숨기기. 전역 Alt+백틱 재입력 또는 메뉴 막대/트레이에서 복원 |
| 실행 중 설정 | 위치, 펼친 크기, 색상 모드, 불투명도, 접힘 여부, 클릭 통과. 현재 시작 동작은 구현 현황 기준 |
| 화면 경계 | 현재 크기 조절·프리셋·접힘 경로에서 작업 영역에 맞춤. 모니터 변경 자동 대응은 미구현 |

크기 변경 시 단순히 화면 전체를 축소하지 않는다. 간격과 줄바꿈을 먼저 조절하고 본문 글씨는 최소 11 DIP, 버튼의 실제 클릭 영역은 최소 24 × 24 DIP를 유지한다. 정보가 많으면 내용 영역만 스크롤하고 주요 상태와 동작 버튼은 계속 보인다. 현재 블랙잭의 카드 영역 배치는 [블랙잭 제품 설계](../games/blackjack/product-design.md#2-블랙잭-화면-구성)를 따른다.
사용자 정의 크기 조절의 OS별 확인 범위는 실제 검증 기록을 따르며 다른 OS까지 통과했다고 추정하지 않는다.

### 투명도와 흑백

- 창 배경 기본 알파 0%, 테두리와 그림자 없음.
- 전경은 검정 또는 흰색 중 수동 선택. 반대색의 얇은 외곽선으로 복잡한 화면에서 글자 윤곽 유지.
- 펼친 창 우측 상단의 흑백 색상 전환 버튼에 마우스를 올리면 별도 불투명도 조절창이 나타난다. 조절창의 슬라이더로 전경 불투명도를 조절한다. 기본 65%, 범위 20–100%(5% 단위)이며 20% 미만으로 내려 완전히 안 보이게 할 수 없다. 창 배경은 계속 투명하다.
- 조절창은 색상 버튼의 좌우 중 화면 작업 영역을 벗어나지 않는 쪽으로 열고, 위아래도 작업 영역 안에 맞춘다. 버튼에서 조절창으로 마우스를 옮기는 동안 유지되며 둘 다 벗어나면 닫힌다.
- 게임 창에 마우스가 올라오면 전경 100%, 벗어나면 0.8초 후 설정값으로 복귀한다. 조절창에서 슬라이더를 조작하는 동안에는 선택한 불투명도를 즉시 미리 본다.
- 모든 문양과 상태는 흑백. 결과는 색 대신 문구와 금액으로 구분한다. 현재 블랙잭의 결과 표현은 [블랙잭 화면 구성](../games/blackjack/product-design.md#2-블랙잭-화면-구성)을 따른다.

### 입력 모드

1. **플레이 모드:** 버튼과 정보 영역에서 마우스로 조작한다. 드래그와 크기 조절도 이 모드에서 사용한다.
2. **클릭 통과 모드:** 창 전체의 마우스 입력을 아래 앱으로 통과시킨다. 이 상태에서는 오버레이 안의 버튼도 누를 수 없으므로 메뉴 막대/트레이에서 플레이 모드로 복귀한다.
3. **접기 / 숨기기:** 현재 블랙잭의 진행 중인 판을 초기화하지 않는다. 창의 표시만 바뀌며 딜러 자동 진행과 단계별 저장은 계속된다. 다시 펼치거나 복원하면 그때의 최신 판을 보여 준다.

투명한 픽셀이라고 자동으로 클릭이 통과한다고 가정하지 않는다. 현재 제품은 창 전체의 명시적인 클릭 통과 모드를 제공한다. 자동 부분 통과는 현재 제공 기능이 아니다. 클릭 통과 상태에서 창을 복원해도 메뉴 막대/트레이에서 항상 해제할 수 있어야 한다. 전역 게임 단축키는 초기 범위에서 제외해 다른 앱에서 입력하는 키가 게임 동작을 일으키지 않게 한다. 예외인 Alt+백틱은 창 숨기기/복원만 토글하며 게임 동작을 하지 않는다. 보이는 상태에서는 숨기고, 숨겨진 상태에서는 트레이의 **보이기**와 같은 경로로 복원한다(포커스를 가져오지 않고 클릭 통과도 해제). 다른 앱에서 해당 단축키를 이미 점유했다면 등록하지 못할 수 있으며 메뉴 숨기기·복원은 계속 이용할 수 있다. 자동으로 창을 띄우거나 복원할 때 다른 앱의 키보드 포커스를 빼앗지 않는 것이 목표다.

전체 화면 앱, Spaces 이동, 다중 모니터에서의 표시 방식은 창 검증에서 확인한다. 일반 창 위에 유지되는 기능과 전체 화면 위 표시 가능 여부는 구분해 검증한다.

## 3. 메인 기능 완료 기준

기존 창 기능은 새 게임을 추가해도 유지한다. 투명·흑백 표시, 사용자 크기 조절, 불투명도, 숨김·복원, 전체 클릭 통과와 트레이 경로가 게임 선택에 따라 사라져서는 안 된다. 최소 크기에서도 주요 조작을 사용할 수 있어야 한다.

기존 O 시나리오는 변경된 경로의 회귀 기준으로 활용한다. 실제 외부 앱 포커스·물리 키·OS 합성은 확인한 환경과 결과만 기록한다. 구 창 프로토타입·일괄 제품화 세션의 미완료 게이트는 폐기했으며 새로운 작업 완료 조건은 [로드맵](../work-session-roadmap.md)이 정한다.

현재 구현·미검증 범위는 [메인 구현 현황](implementation-status.md)과 [E2E 현황](e2e-implementation-status.md), 신규 메뉴·공용 잔액 검증은 [메인 APP 시나리오](e2e-test-plan.md)를 따른다.

## 4. 범위와 다음 작업

- 계정·서버·실물 결제는 첫 버전 범위 밖이다.
- 자동 배경 분석과 자동 색상 전환은 첫 버전 범위 밖이다.
- 사운드와 장시간 애니메이션은 첫 버전 범위 밖이다.
- 화면 캡처·공유에서 창을 제외하는 기능은 첫 버전 범위 밖이다. 일반적인 투명 창은 캡처에 보일 수 있다.
- 2026-09-18에 기존 미진행 세션과 TOBE 백로그를 폐기했다. 다음 구현 범위는 새 로드맵에서만 정한다.

현재 구현과 미구현 항목은 [메인 기능 구현 현황](implementation-status.md), 다음 세션과 작업 순서는 [작업 세션 로드맵](../work-session-roadmap.md)을 참조한다.


## 5. 메인 메뉴와 공용 잔액의 신규 설계

**상태:** 2026-09-18 재설계. 아래는 N02~N05에서 구현할 계약이며 현재 제공 기능이 아니다.

### 사용자 결정

- 모든 게임이 하나의 잔액을 사용한다. 최초 금액과 전체 새 시작 금액은 기존과 같은 **$100.00**다.
- 한 판이 진행 중이면 메뉴·다른 게임으로 이동할 수 없다. 판이 끝나면 메뉴로 돌아갈 수 있다.
- 새 시작은 메인 메뉴에서 수행한다. 게임별 돈을 별도로 지급하거나 게임 진입 때 충전하지 않는다.
- 바카라는 기본 수수료 방식, 한 곳 베팅, 최근 P·B·T 한 줄을 제공한다. 규칙 상세는 [바카라 제품 설계](../games/baccarat/product-design.md)를 따른다.

### 시작 화면과 메뉴

미완료 판이 없으면 앱 실행 시 메인 메뉴를 표시한다. 저장된 미완료 판이 있으면 해당 게임을 먼저 복원한다. 블랙잭은 사용자 선택 지점에서 이어지고 자동 진행 단계는 Main에서 재개한다. 저장 복구가 필요하면 복구 안내를 먼저 보여 주며 자동 새 시작을 하지 않는다.

메뉴는 기존 투명 오버레이 안의 한 페이지다. 공통 헤더에 드래그·흑백 전환·숨김·종료를 유지하고, 내용에 공용 잔액, 블랙잭·바카라 선택 항목, 새 시작을 배치한다. 처음에는 바카라를 준비 중으로 표시하고 구현 완료 후 활성화한다. 메뉴에서 게임별 잔액을 표시하지 않는다.

게임 화면에 메뉴 버튼을 추가한다. 비활성 상태의 첫 클릭과 기존 불투명도·크기 조절·Alt+백틱을 유지한다. 메뉴 자체는 키보드 포커스를 요구하지 않는다. 220×150 DIP에서도 게임 선택과 핵심 조작을 숨기지 않는다.

### 이동 가능한 시점

| 상태 | 메뉴·다른 게임 이동 | 사용자 경험 |
| --- | --- | --- |
| 베팅 전 | 허용 | 입력 중인 미확정 금액은 취소하고 이동 |
| 블랙잭 보험 결정·플레이어/딜러 진행 | 금지 | 메뉴 버튼 비활성, 한 판을 마치면 이동 가능 안내 |
| 바카라 배분·정산 진행 | 금지 | 결과 확정까지 현재 게임 유지 |
| 결과가 저장된 뒤 | 허용 | 자동 이동하지 않고 다음 판 또는 메뉴를 선택 |
| 명령 저장 중·저장 실패 | 금지 | 완료 대기 또는 같은 저장 재시도 |
| 판 종료 뒤 잔액 $1 미만 | 허용 | 새 베팅은 막고 메뉴의 새 시작을 안내 |

숨김·앱 종료는 메뉴 이동과 다르다. Alt+백틱은 진행 중에도 창을 숨기며 게임을 취소하지 않는다. 숨김 중 자동 진행·저장은 계속되고, 정상/강제 종료 후에는 저장된 미완료 판을 복원한다. 메뉴와 딜을 동시에 요청해도 Main에서 한 순서로 처리한다.

게임 이동은 게임별 슈·최근 결과·확정된 베팅 설정을 보존한다. 게임에 재진입했을 때 이전 금액이 공용 잔액을 넘으면 새 베팅 전에 조정한다. 정산된 결과의 과거 금액은 바꾸지 않는다. 바카라 기록도 메뉴 이동·재실행으로 지우지 않는다.

### 전체 새 시작

미완료 판이 없고 저장 오류가 없는 메인 메뉴에서 새 시작을 선택할 수 있다. 잔액 부족 시 이 경로를 안내하고, 잔액이 남아 있을 때도 사용자가 명시적으로 선택할 수 있다. 확인 문구는 “잔액을 $100으로 초기화하고 모든 게임의 판·슈·기록을 새로 시작합니다”로 범위를 밝힌다. 취소하면 변경하지 않는다.

확정하면 공용 잔액 $100, 기본 베팅 설정, 미진행 상태와 빈 기록을 하나의 저장으로 교체한다. 게임별 슈는 기존 슈를 폐기하고 새로 생성하거나 첫 진입 때 생성한다. 게임 화면의 기존 블랙잭 새 게임 동작은 이 공용 초기화 경로로 대체한다. 진행 중 판을 메뉴 이동·초기화로 회피할 수 없다.

기존 블랙잭 사용자는 **현재 잔액을 그대로 이전**한다. 초기 $100을 더하거나 잔액을 $100으로 덮어쓰지 않는다. 손상 파일 복구와 사용자가 선택하는 전체 새 시작은 [공용 저장 계약](technical-design.md#9-여러-게임과-공용-잔액의-신규-계약)을 따른다.
