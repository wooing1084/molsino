## 2. 베팅과 정산

- 복수 구역에 베팅할 수 있다. 구역별 금액은 정수 센트이며 0은 해당 구역 베팅 제거다. 음수·소수 센트·알 수 없는 구역을 거부한다.
- 앱의 공통 한도를 한 판의 총 베팅에 적용한다. 합계가 선택 레벨의 최소 이상·최대 이하이며 잔액 이하여야 회전할 수 있다. 이것은 공통 테이블 정책에 맞춘 앱 운영 결정이다. 각 양수 구역은 최소 1센트이며 UI에 한도가 총액 기준임을 표시한다.
- 최초 진입은 실버에 현재 레벨 최소 금액을 준비한다. 베팅 수정은 지갑을 차감하지 않는다. 회전 시작에서 총액을 한 번 차감한다.
- 반환금 = 당첨 구역 베팅액 × (순이익 배당 + 1). 다른 구역 베팅은 잃는다. 순손익 = 반환금 − 전체 베팅액이다. 무당첨 반환은 0이며 수수료는 없다.
- 회전 시작 전에 가능한 모든 결과의 반환·최종 잔액이 안전 정수 범위인지 검사한다. 중복 명령·저장 재시도·재시작은 중복 차감·지급을 만들지 않는다.
- 다음 판은 직전 베팅 구성을 가능한 경우 유지한다. 다른 게임의 잔액 변동·레벨 변경으로 총액이 허용 범위를 벗어나면 실버의 가능한 기본 베팅으로 재설정한다. 잔액이 최소 미만이면 기존 공통 잔액 부족 동작을 따른다.

## 3. 플레이와 화면

메뉴의 빅휠 → 구역 선택과 금액 수정 → 회전 → 당첨 구역·반환·순손익 → 다음 판/메뉴 순서다. 선택 구역 제거를 제공하고 베팅 구역·합계·7개 배당을 확인할 수 있어야 한다.

회전 중 베팅·다음 판·메뉴·레벨·전체 초기화를 Main과 UI 양쪽에서 잠근다. 아래 세 칸 확대 영역과 고정 포인터로 회전·결과를 표시한다. 표시 연출은 약 1.8초이며 Main 정산과 독립이다. 결과·최종 잔액·최근 기록·최고 잔액을 회전 연출 완료 시 함께 표시한다. 저장 오류는 기존 후보의 저장 재시도를 제공한다.

최근 결과는 최대 20개를 표시한다. 기존 220×150 최소 창, 흰색/검정, 불투명도, 금액 편집 포커스, 숨김·복원을 유지한다. 재기동/reload는 저장된 판을 복원하며 이미 정산된 결과의 연출을 다시 강제하지 않는다.

### 3.1 결과 주변 세 칸 확대

작은 원형 휠 전체를 그리던 영역을 **휠의 당첨 지점을 확대해 보는 가로 창**으로 교체한다. 별도의 확대 버튼 없이 기본 표시로 사용한다. 세 칸은 최근 세 판이나 별개의 추첨 결과가 아니라 같은 54칸 휠의 연속한 이웃 칸이다.

```text
                      ▼ 고정 포인터
 [왼쪽 이웃 칸]   [가운데 결과 칸]   [오른쪽 이웃 칸]
   작게·흐리게       크게·선명하게       작게·흐리게
```

- 가운데 칸은 구역 이름을 온전히 읽을 수 있게 표시한다. 멈춘 뒤 이름·순이익 배당과 테두리/굵기로 당첨을 강조한다. 조커와 메가는 배당이 같아도 이름으로 구분한다.
- 양옆은 인접 칸의 일부가 보이는 형태로 작고 흐리게 표시한다. 작은 창에서 양옆 가장자리의 잘림은 허용하되 중앙 구역 이름·당첨 배당은 가리지 않는다. 흑백 모두 색상 없이 위치·크기·테두리로 중앙을 식별한다.
- 칸들은 오른쪽에서 왼쪽으로 연속 이동한다. 고정 포인터 아래로 빠르게 지나가다가 서서히 감속하여 Main이 확정한 칸의 중심에 멈춘다. 칸 경계도 함께 움직여 같은 구역이 연속되어도 이동이 보이게 한다.
- 현재 고정 배열의 순서와 칸 수를 유지한다. 같은 구역이 두세 칸 연속 보일 수 있으며, 보기 좋게 만들려고 양옆을 다른 구역으로 바꾸거나 당첨에 가까웠던 것처럼 조작하지 않는다.
- 베팅 전에는 중립적인 세 칸 미리보기와 ‘회전 대기’를 표시하며 당첨 강조를 하지 않는다. 다음 판에서 직전 당첨을 현재 판 결과처럼 표시하지 않는다.
- 회전 중에는 ‘회전 중’을 표시하고 결과 강조를 하지 않는다. Main 결과가 늦으면 진행 표시를 유지하다가 확정 칸으로 감속한다. 약 1.8초는 정상 응답 시 연출 기준이며 늦은 응답 때문에 임의 칸에 최종 정지하지 않는다.
- 최종 정지와 함께 당첨 이름·배당·반환금·순손익·최종 잔액·최근 기록·최고 기록을 공개한다. `prefers-reduced-motion`에서는 가로 이동을 생략하고 중립적인 진행 표시 후 동일한 결과를 공개한다.
- 이미 정산된 판의 reload·재진입·숨김 복원은 결과 세 칸을 즉시 표시한다. 미정산 판은 진행 상태로 복원하고 새 추첨을 하지 않는다.

기존 베팅 구역 선택·금액 편집·제거·회전·다음 판 기능과 합계·한도·최근 기록을 유지한다. 합계는 총액 최소·최대 한도 옆에 모아 표시하고, 최근 기록은 휠 아래에 둔다. 최소 220×150에서 세 칸 영역의 읽을 수 있는 크기를 확보하도록 기존 휠 영역과 구역 목록의 폭·배치를 조정하며 구역 목록은 스크롤로 접근한다. 모든 클릭 대상은 24×24 이상, 금액과 한도는 기존 큰 금액 검증 기준을 유지한다. 구체적인 폭·높이는 구현 시 최소 창과 280×180에서 검증하며 전체 휠을 단순히 더 작은 세 칸으로 바꾸지 않는다.

## 4. 완료 조건

순수 배분·7개 배당·복수 베팅·금액 경계 테스트와 공용 저장/이전/중복 명령 테스트를 통과한다. 프로덕션 Electron 패키지에서 메뉴 선택·회전·정산·최소 창·세 게임 왕복·진행 판 재시작·저장 실패 재시도를 검증한다. 구현 현황과 세션 보고서에는 실제 실행 범위 및 미검증 환경을 구분한다.

세 칸 확대의 완료 조건은 [E2E 설계의 BW-11~14](e2e-test-plan.md#3-세-칸-확대-검증)다. 실제 구현·패키지 검증 범위는 [후속 보고서](../../session-reports/N05-bigwheel-result-zoom.md)를 따른다.
