# N06 영어 현지화

**목적:** 작은 오버레이 안에 설정 UI를 추가하지 않고 네이티브 메뉴에서 한국어·영어를 전환하며, 앱 전체 표시와 선택 언어를 안전하게 유지한 구현·검증 결과를 기록한다.

**요약:** 최신 `DEV`에서 설계를 먼저 확정하고 현지화 E2E의 RED를 확인한 뒤 구현했다. macOS는 애플리케이션 메뉴와 상태 아이콘 메뉴, Windows는 알림 영역 tray 메뉴를 사용한다. 한국어를 기본값으로 유지하며 영어 전환은 게임 상태를 바꾸지 않고 별도 환경설정에 저장한다.

## 1. 작업 범위와 결정

- `DEV`를 `origin/DEV`의 `82b1067`까지 fast-forward한 뒤 작업 브랜치를 만들었다.
- `30e4a0e`에서 [제품 설계 §7](../main/product-design.md#7-한국어영어와-네이티브-언어-메뉴), [기술 설계 §10](../main/technical-design.md#10-영어-현지화와-네이티브-언어-메뉴), N06 E2E 범위와 로드맵을 구현 전에 기록했다.
- Electron의 공식 `Menu` 계약상 macOS 애플리케이션 메뉴는 전역 메뉴이고 Windows/Linux 메뉴는 개별 창 상단에 붙는다. 220×150 프레임리스 오버레이의 공간을 소비하지 않도록 Windows 애플리케이션 메뉴는 제거하고 알림 영역 tray 메뉴를 공통 진입점으로 선택했다. macOS는 상단 애플리케이션 메뉴와 상태 아이콘 메뉴를 모두 제공한다.
- 한국어를 초기 기본값으로 유지하고 이번 범위에는 영어만 추가했다. 언어 전환은 게임 세션 revision·화면·잔액·진행 판·연출 상태를 바꾸지 않는다.
- 언어는 `app-session.json`이 아닌 `preferences.json`에 저장한다. 전체 새 시작, 게임 저장 복구와 언어 설정의 수명과 실패를 분리했다. 저장 성공 후에만 화면과 네이티브 메뉴를 전환한다.

## 2. 구현 내용

- `src/shared/i18n.ts`에 타입이 맞는 한국어·영어 카탈로그, 보간, 명령 오류와 빅휠 이름 번역을 추가했다. Renderer는 Main/Core의 raw 한국어 오류 문자열 대신 공개 오류 코드를 현재 언어로 표시한다.
- Main이 시작할 때 별도 환경설정을 읽고 `OverlayViewState.locale`로 메인 창과 불투명도 창에 배포한다. 언어 변경을 원자 저장하고 메뉴의 radio 선택·Renderer·네이티브 대화상자를 다시 구성한다.
- 메인 메뉴·복구·레벨·블랙잭·바카라·빅휠·금액 입력·상태 문구와 접근성 이름을 번역했다. 문서의 `lang`도 현재 언어와 동기화한다.
- macOS 애플리케이션 메뉴와 macOS/Windows tray 메뉴를 순수 템플릿 빌더로 분리했다. Windows 프레임리스 창에는 메뉴 막대를 추가하지 않는다.
- `bfdbcb8`에서 N06 E2E를 선작성했고 `2fd62f9`에서 구현과 환경설정·네이티브 메뉴·금액 오류 단위 테스트를 커밋했다.

## 3. 검증 기록

### 변경 전 RED

`bfdbcb8`의 `tests/e2e/localization.spec.ts`를 기존 소스의 macOS arm64 프로덕션 패키지에서 실행했다. 언어 메뉴와 영어 동작이 없어서 5개가 모두 실패했다. 이 실패를 확인한 뒤 제품 코드를 구현했다.

### 구현 후 결과

최종 소스로 macOS arm64 프로덕션 패키지를 다시 생성하고 격리된 `userData`에서 검증했다.

관련 99개 고유 사례는 후속 재실행까지 합치면 모두 통과했다. 다만 한 번의 99개 통합 실행이 전부 초록이었다고 주장하지 않는다. 소스나 테스트 변경 없이 N04-03 단독 및 그 사례를 포함한 전체 파일이 이어서 통과했으므로 일시적 실행 실패로 기록한다.

N06 E2E는 macOS 네이티브 애플리케이션 메뉴를 통한 즉시 전환, `preferences.json` 저장·Renderer reload·앱 재실행·전체 새 시작 후 보존, 진행 중 판의 상태 불변, 메인·레벨·세 게임·복구·금액 오류·불투명도 창의 영어 표시, 설정 저장 실패 시 한국어와 기존 메뉴 선택 상태 유지까지 확인한다. 저장 실패 대화상자는 테스트에서 응답을 가로채 메시지를 확인했다.

220×150 영어 빅휠 캡처를 직접 확인했다. Menu·잔액·세 칸 휠·최근 결과·한도·금액 입력·Remove·Spin·상태가 창 안에서 읽히고 핵심 조작이 유지됐다. 임시 캡처는 `/private/tmp/molsino-localization-green`에 생성했으며 영구 보관을 보장하지 않는다.

로컬 셸에는 프로젝트가 지정한 Node 22.22.1과 npm 실행 파일이 없었다. 설치된 프로젝트 도구를 번들 Node 24.19.0 및 npm 버전 확인용 임시 shim으로 실행했다. 타입·단위·패키지·실제 Electron E2E 결과는 위와 같지만, 이 세션이 선언된 Node 22 런타임에서의 로컬 재검증까지 수행했다고 주장하지 않는다.

## 4. 남은 범위와 다음 시작점

Windows용 네이티브 메뉴 템플릿은 단위 테스트에서 애플리케이션 메뉴가 `null`이고 tray에 한국어·English radio 선택이 있음을 확인했다. 실제 Windows GUI의 알림 영역 아이콘 클릭·radio 표시·전환은 이번 macOS 환경에서 물리 검증하지 않았다. macOS 상태 아이콘의 물리 클릭, 외부 앱 포커스, 실제 투명 합성도 자동화 결과로 통과 처리하지 않는다.

다음 작업은 [로드맵](../work-session-roadmap.md)의 N07 macOS 서명과 Mac App Store 제출이다. 제출 시점의 Apple 요구사항을 다시 확인하고 최신 `DEV`에서 별도 브랜치로 시작한다. DEV 병합은 이번 세션에서 수행하지 않는다.
