### 현행 패키지의 UI 관찰

실행 환경은 macOS arm64, Node.js **22.22.1**, npm **10.9.4**다. 기존 arm64 패키지는 N06 언어 메뉴가 없는 이전 번들이었으므로 현재 UI를 대조하기 위해 `npm run package`로 다시 만들었다. 첫 실행은 제한된 네트워크에서 `getaddrinfo ENOTFOUND github.com`으로 실패했으며, 네트워크 접근을 허용한 재실행은 성공했다. 패키지의 Main 번들이 현재 `.vite/build/main.js`와 동일함을 확인했다. 문서 변경에 대한 필수 빌드 게이트를 새로 추가한 것은 아니다.

기존 Playwright Electron API를 임시 조작·관찰 스크립트에서 사용했다. 별도 임시 `userData`에서 220×150 창을 열었으며 기존 사용자 저장 데이터는 건드리지 않았다. 새 테스트 파일이나 정식 테스트 스위트를 추가·실행하지 않았고 앱 전체 회귀도 실행하지 않았다.

| 관찰한 경로 | 결과 |
| --- | --- |
| 새 사용자 시작·언어 메뉴 | 한국어·$100·Lv.1로 시작, 네이티브 메뉴 콜백으로 한국어/English 전환 |

세 게임 × 두 언어의 **6개 한 판 흐름을 모두 완료**했고 조작 중단은 없었다. 이는 새 자동 테스트의 통과 수가 아니다. 각 게임 결과 화면 6개를 캡처해 표시 위치와 설명을 대조했다. 임시 관찰 로그·캡처는 `/private/tmp/molsino-n07-review-1fTsso/`에 있으며 영구 보관을 보장하지 않는다. 실행한 임시 스크립트는 `node /private/tmp/molsino-n07-walkthrough.cjs`다. 관찰용 앱은 종료했다.

## 3. 미확인 범위와 다음 시작점

macOS 메뉴는 실제 메뉴 객체의 콜백을 호출했으며 상태 아이콘을 물리적으로 클릭한 검증은 아니다. 실제 아래 앱으로의 클릭 전달, 물리 Option/Alt+백틱 입력·단축키 충돌, 외부 앱 포커스, 투명 합성, 전체 화면·다중 모니터, Windows GUI는 이번에 검증하지 않았다.

보험·스플릿·더블·서렌더의 모든 분기, Banker/Tie·일곱 빅휠 구역의 모든 정산, 부족 잔액·저장 실패·백업/손상 복구·재실행 보존 경계는 이번 UI 관찰에서 다시 유도하지 않았다. 해당 안내는 실제 소스와 담당 설계를 대조한 범위다. 과거 자동 테스트 결과를 N07의 새 검증 수로 재사용하지 않았다.

현재 언어 정책은 한국어 첫 실행이며 N08은 미구현이다. 다음 작업은 N07 PR을 `DEV`에 반영한 뒤 최신 `DEV`에서 시작하는 **N08 실행 언어 유지와 첫 실행 언어 선택**이다. 상세 시작 자료·범위는 [로드맵](../work-session-roadmap.md#9-n08--실행-언어-유지와-첫-실행-언어-선택)을 따른다. `DEV` 병합은 이번 세션에서 수행하지 않는다.
