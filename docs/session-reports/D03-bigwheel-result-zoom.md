# D03 빅휠 결과 세 칸 확대 설계

**목적:** 작은 전체 휠을 대신할 결과 주변 확대 표시의 후속 구현 기준을 기록한다.

**요약:** 사용자 요청에 따라 제품·기술·E2E 설계를 수정했다. 좌·중앙·우 실제 이웃 칸과 고정 포인터, 가로 이동·감속·결과 공개를 정의했으며 구현은 변경하지 않았다.

## 설계 변경

- [제품 설계 §3.1](../games/bigwheel/product-design.md#31-결과-주변-세-칸-확대)에 확대 표시·중앙 강조·가로 이동과 감속·최소 창 가독성을 정의했다.
- [기술 설계 §3.1](../games/bigwheel/technical-design.md#31-세-칸-확대-표시-계약)에 실제 칸 매핑·순환 경계·동일 심볼·타임라인·복원 계약을 정의했다. 별도 읽기 전용 리뷰로 현재 코드의 배열과 연출 중 목표 인덱스 노출 경계를 확인했다.
- [E2E 설계 BW-11~14](../games/bigwheel/e2e-test-plan.md#3-세-칸-확대-검증)에 후속 검증 기준을 추가했다. 현재 구현/E2E 현황에는 미구현·미검증임을 명시했다.
- 룰·배당·54칸 순서·저장 형식·정산은 유지하고 표시 개선만 설계했다. 상세 계약은 각 담당 문서가 기준이다.

## 검증과 다음 단계

`git diff --check`와 변경 문서의 상대 파일 링크·앵커를 확인했다. 제품 코드와 테스트 코드는 변경하지 않았으며 앱 패키징·단위/E2E 테스트는 실행하지 않았다. 기존 N05 통과 기록을 새 표시 방식의 검증으로 재사용하지 않는다.

이번 요청 범위는 설계 문서 수정이다. 후속 구현 시 해당 브랜치에서 표시 컴포넌트·타임라인과 BW-11~14를 구현·검증한다. 이번 작업에서 원격 push·DEV 변경·PR 생성은 수행하지 않는다.
