# D04 출시 전 설명서·실행 언어 세션 설계

**목적:** 무료 MVP 출시 전에 요청한 두 개발 세션을 다음 작업으로 바로 시작할 수 있도록 범위·동작·검증·문서 연결을 정리한다.

**요약:** 사용 설명서 작성과 실행 언어 세션을 로드맵에 추가하고 미착수 스토어 제출을 뒤로 옮겼다. 언어 선택 보존은 이미 N06에 있으므로 시스템 언어에 따른 첫 실행과 관련 실패 경계를 새 범위로 정의했다. 이번 작업은 문서 설계이며 설명서와 제품 기능은 아직 구현하지 않았다.

## 1. 반영한 설계

- [로드맵](../work-session-roadmap.md)에 N07 Markdown 사용 설명서와 N08 실행 언어 유지·첫 실행 언어 선택을 추가했다. 기존 미착수 macOS 서명·Mac App Store 제출은 N09로 이동하고 N06 등 완료 세션의 이력은 유지했다.
- [사용 설명서 작성 설계](../main/user-guide-design.md)에 루트 Markdown 파일, 한국어·English 안내, 실제 창 조작·세 게임·공용 잔액·저장·문제 해결과 문서 검증을 정의했다. 앱 내 도움말 UI나 웹사이트는 추가 범위로 만들지 않았다.
- 언어의 신규 사용자 동작은 [제품 설계 §7.1](../main/product-design.md#71-n08-실행-언어-유지와-첫-실행-언어-선택), Main·설정 저장과 실패 경계는 [기술 설계 §10.5](../main/technical-design.md#105-n08-첫-실행-언어-결정과-보존), 검사 기준은 [N08 검증 계획](../main/e2e-test-plan.md#6-n08-실행-언어-유지와-첫-실행-언어-선택)에 두었다.
- AGENT·문서 색인·문서 작성 가이드에서 해당 설계로 연결하고 구현/E2E 현황에는 미구현·미검증으로 표시했다. N07 작성 문서의 첫 실행 안내를 N08에서 후속 갱신하도록 연결했다.

## 2. 검증과 범위

현재 Main 시작 경로·preferences 저장소·네이티브 메뉴·N06 테스트를 읽고 언어 보존의 기존 구현과 미구현 첫 실행 정책을 구분했다. 읽기 전용 보조 검토로 설정 없음/손상/백업·저장 실패 경계를 확인하고 Electron의 공식 선호 시스템 언어 API를 대조했다.

`git diff --check`와 변경 Markdown 문서의 상대 파일 링크·앵커를 확인했다. 제품 코드·테스트 코드·README의 현재 동작 설명은 변경하지 않았으며 앱 패키징·단위/E2E 테스트는 이번 설계 작업에서 실행하지 않았다. 이전 테스트 통과 수는 새 계획의 완료 근거로 재사용하지 않는다. 원격 push·PR 생성과 스토어 업로드는 이번 문서 반영에서 수행하지 않았다.

창 위치 복귀·다른 창 설정 저장·추가 게임·계정·클라우드·수익화와 이전에 폐기한 수정 세션은 추가하지 않았다. 이번 계획이 스토어 승인이나 모든 OS 검증의 완료를 뜻하지 않는다.

## 3. 다음 시작점

다음 구현자는 `AGENT.md` → [로드맵](../work-session-roadmap.md) → [사용 설명서 설계](../main/user-guide-design.md) 순으로 읽고 N07을 시작한다. N07의 설명서 작성 후 N08 언어 기능을 구현·검증하며, 그 다음 N09의 서명·제출을 진행한다. 세션 완료 상태와 다음 작업의 기준은 로드맵 한 곳에서 관리한다.
