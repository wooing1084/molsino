# S10.5 — 인라인 베팅 금액 입력과 게임 오버 경계

상태: 완료
완료일: 2026-09-17

## 범위와 결정

- 베팅 금액 숫자칸을 누르면 같은 자리의 텍스트 필드로 전환한다. Enter로 저장하고 Escape·필드 밖 클릭으로 취소한다. 텍스트는 달러 단위로 받고 소수 둘째 자리까지만 정수 센트로 변환한다. 허용 범위는 $1.00~min($500.00, 현재 잔액)이다.
- 기본 오버레이는 `focusable:false`다. 금액 편집을 명시적으로 시작할 때만 Main이 포커스 가능 상태로 바꾸고, 확정·취소·blur·숨김·접힘·클릭 통과·reload에서는 `blur()` 후 비활성으로 되돌린다. 편집 중 딜은 Main에서도 거부한다.
- 센트 베팅의 자연 블랙잭 3:2와 서렌더 절반 반환에서 반 센트가 생기면 올림한다. 보험의 $0.50 단위와 −/+ 증감 단위는 유지한다. 기존 정수 달러 저장 세션도 그대로 읽는다.
- 라운드 정산 후 잔액 $1.00이면 $1.00 베팅으로 다음 판을 진행할 수 있다. $1.00 미만이면 결과 화면에 게임 오버를 표시하고 다음 판·베팅·딜을 막는다. 앱은 계속 실행하고 새 게임을 제공한다. 판 도중 사용 가능 잔액이 낮아져도 현재 판은 끝까지 정산한다.

## 변경사항

- `src/renderer/main.tsx`, `src/renderer/styles.css`, `src/shared/bet-input.ts`: 숫자칸과 입력 필드의 제자리 전환, 정확한 문자열→센트 파싱, 입력 오류·취소·저장 상태, 최소 크기 베팅 행.
- `src/main/main.ts`, `src/shared/contracts.ts`, `src/preload/preload.ts`: 신뢰된 메인 문서 전용 편집 포커스 IPC, 숨김·접힘·reload 수명 정리, 편집 중 딜 차단.
- `src/core/betting.ts`, `src/core/rules.ts`, `src/core/engine.ts`, `src/core/settlement.ts`: 1센트 단위 베팅 검증, 다음 판 센트 상한, 게임 오버 경계, 반 센트 반환금 올림과 저장 상태 무결성.
- `forge.config.cjs`: 로컬 Electron ZIP이 있을 때 `MOLSINO_ELECTRON_ZIP_DIR`로 다운로드 없이 패키징할 수 있게 했다. 설정하지 않으면 기존 패키징 경로를 사용한다.
- `tests/e2e/betting.spec.ts`: S10.5 7건. 기존 S09 Preload API 기대 목록과 관련 코어·공유 계약 테스트도 갱신했다.

## 검증 결과

- 선작성 red: S10.5-01은 금액 숫자칸에 클릭 가능한 입력 기능이 없어 의도한 이유로 실패했다. 최초 패키징은 sandbox 네트워크 제한으로 Electron ZIP 다운로드에 실패했으며, 로컬 ZIP 경로를 사용한 프로덕션 패키지에서 red를 확인했다.
- 공식 완료 검증: macOS arm64, Electron 44.3.0, Forge 프로덕션 패키지 `npm run test:e2e` 전체 39/39 통과(S10.5 신규 7건), 실패·스킵 0. `npm run check`는 13파일 131/131 통과.
- 금액 전환·유효/무효 입력·취소·숨김/접힘/클릭 통과/reload 포커스 복귀, 220×150 DIP 입력칸 배치, $500 상한, 센트 베팅 재기동 복원, $1.01 자연 블랙잭·서렌더 반환금, 정산 뒤 $1.00에서 $1 딜·$0.99에서 게임 오버/새 게임 경계를 자동 확인했다.

## 관련 이슈와 다음 시작점

- E2E는 Electron 창의 `isFocusable()`과 화면·저장 상태를 확인한다. 실제 외부 업무 앱의 포커스 복귀와 Windows GUI 동작은 실장비에서 확인하지 못했다.
- 다음 시작점은 S11 위치·다중 모니터와 시작 기본값이다. 음수 좌표·화면 밖 보정, 모니터 배치 변경과 재실행 시 창 설정 초기화를 E2E부터 검증한다. 게임 세션은 계속 복원하고 `preferences.json`은 만들지 않는다.
