# D02 — 게임성 개선 설계

**목적:** 플레이 피드백을 N04의 수정안으로 구체화하고 스토어 제출을 후속 세션으로 배치한다.

**요약:** 투명도 조절창 동기화·테이블 한도와 레벨 선택 페이지·카드 순차 공개의 초안을 작성했다. 수치와 입장 정책은 제안이며 구현 완료 기록이 아니다.

## 1. 작업 내용

- N04를 게임성 개선, N05를 macOS 서명과 Mac App Store 제출로 로드맵에 반영했다.
- 사용자 확인으로 투명도 개선 대상이 별도 슬라이더 창임을 명확히 했다.
- 사용자 후속 의견을 반영해 레벨 선택을 별도 팝업이나 텍스트 필드 대신 기존 창 안의 좌우 카드 목록 페이지로 설계하고, 확정된 레벨을 공통 상단에 항상 표시하기로 했다.
- 사용자 최종 방향에 따라 모든 게임에 레벨별 동일한 최소·최대 기본 베팅액을 적용하고 게임 화면에 한도를 상시 표시하도록 설계를 단순화했다. 게임별 세부 조정은 후속 검토로 미뤘다.
- 카지노 한도 조사표와 운영사 안내를 확인했다. 실제 사례와 게임용으로 조정한 금액을 구분했다.
- ‘연속 증액 차단’이 아니라 ‘테이블별 최대 베팅액 적용’임을 설명했다. 상한 안의 증액과 자격을 갖춘 상위 방 이동은 허용하는 안이다.
- 현재 코드에서 조절창에 공통 알파 스타일이 없고 자동 진행 간격이 0ms이며 카드·합계가 즉시 표시되는 구조를 확인했다.

상세 제안은 [게임성 개선 설계안](../main/gameplay-improvements-design.md)이 소유한다.

## 2. 확인과 남은 결정

- 문서 변경에 대해 `git diff --check`를 통과했다. 게임 코드 변경과 테스트 실행은 하지 않았다.
- 레벨별 입장 잔액·최소/최대액, 현재 잔액 기반 입장과 영구 해금 중 선택, 카드 공개 속도는 아직 미확정이다.
- 다음은 설계 의견을 반영해 담당 제품·기술·E2E 기준을 확정하고 N04를 구현하는 것이다. 이번 초안을 N04 구현 완료로 간주하지 않는다.
