# molsino v0.0.4 릴리즈 노트

**목적:** v0.0.4에서 사용자가 새로 이용할 수 있는 기능과 설치 전 확인할 내용을 안내한다.

**요약:** 메인 메뉴와 공용 잔액을 도입하고 기본 수수료 바카라를 추가했다. 기존 블랙잭 저장은 잔액과 진행 중인 판을 유지한 채 새 앱 세션 형식으로 이전하며, 두 게임 모두 저장 실패·강제 종료 후 복구를 지원한다.

## 주요 변경

### 두 게임을 연결하는 메인 메뉴

- 앱을 실행하면 공용 잔액과 블랙잭·바카라 선택 화면이 표시된다.
- 두 게임은 같은 잔액을 사용한다. 한 게임의 결과가 다른 게임에서도 즉시 반영된다.
- 판이 진행 중일 때는 다른 게임이나 메뉴로 이동할 수 없다. 정산이 저장된 뒤 이동할 수 있다.
- 메뉴의 **새 시작**에서 확인 후 잔액을 $100.00으로 초기화하고 두 게임의 슈·판·기록을 함께 지울 수 있다.

### 기본 수수료 바카라

- Player·Banker·Tie 중 한 곳과 $1.00 이상의 금액을 선택해 플레이한다.
- 8덱 슈와 표준 세 번째 카드 규칙을 적용하며, 카드 배분과 정산은 자동으로 진행된다.
- Banker 승리는 5% 수수료를 반영하고, Tie 적중은 베팅 원금을 포함해 9배를 반환한다.
- 최근 완료한 20판을 P·B·T 한 줄 기록으로 표시한다.
- 카드 배분 중 앱을 숨기거나 종료해도 저장된 단계에서 이어서 진행한다.

### 블랙잭과 저장 신뢰성

- 기존 블랙잭 규칙·센트 베팅·보험·스플릿·서렌더·딜러 자동 진행을 유지한다.
- 저장 실패 시 계산된 같은 후보를 재시도해 카드 추첨·베팅 차감·결과 지급이 중복되지 않게 한다.
- 앱 명령에 세션·명령·상태 revision을 검사하고, 현재 화면이 아닌 게임의 명령과 내부 자동 진행 명령을 거부한다.
- Renderer에 슈·버린 카드·미래 카드·내부 정산 증거를 노출하지 않는다.

## 저장 데이터와 호환성

- 기존 `session.json`의 블랙잭 잔액·슈·진행 중인 판·보험·스플릿·정산 기록을 새 `app-session.json`으로 이전한다.
- 이전 과정에서 $100.00을 추가 지급하거나 현재 잔액을 초기화하지 않는다.
- 이전한 기존 파일은 변경하거나 삭제하지 않는다.
- 새 저장 파일이 손상됐거나 지원하지 않는 미래 버전이면 자동으로 초기화하지 않고 복구 화면을 표시한다.
- 바카라는 별도 지갑 파일을 만들지 않고 블랙잭과 같은 앱 세션에 저장한다.

## 검증 범위

- macOS 26.4.1 arm64에서 타입 검사와 하위 테스트 154개를 통과했다.
- 프로덕션 Electron 패키지에서 블랙잭·바카라·메뉴·저장·IPC·오버레이 E2E 73개 시나리오를 확인했다.
- 바카라의 Player·Banker·Tie 배당, Banker 수수료 반올림, 모든 저장 단계의 강제 종료 복구, 저장 실패 재시도, 컷 경계, 최근 20개 기록과 두 게임 왕복을 포함한다.
- Windows 배포 빌드는 GitHub Actions가 태그에서 생성한다. Windows 실장비의 창 동작·투명 합성·SmartScreen 흐름은 이번 릴리즈에서 직접 확인하지 않았다.

## 설치 시 참고

- macOS 앱은 아직 서명·공증되지 않았다. 실행이 차단되면 앱을 한 번 연 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 허용한다.
- Windows 설치 파일과 포터블 앱도 코드 서명 전이므로 SmartScreen 경고가 표시될 수 있다. 출처를 확인한 뒤 실행한다.
- Windows 포터블 ZIP은 전체를 압축 해제하고 폴더 안의 `molsino.exe`를 실행한다. EXE 파일만 분리하면 필요한 리소스를 찾지 못한다.
